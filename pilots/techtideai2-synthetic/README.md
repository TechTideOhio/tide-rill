# TechTideAI2 synthetic retrieval pilot

Status: **pilot run completed against an uncommitted local fix; full repository verification blocked**. These fictional chunks contain no production data. An independent AI reviewer inspected the corpus and draft labels before the run and agreed with all 24 grades. The reviewer also saw the draft labels, so this is a blind-to-results review, not an independently created judgment set or human adjudication. See `review.json`.

Target source: `Alexi5000/TechTideAI2`, commit `ee82ad39f8e322d5ca2c4cf4a474c993a646eb95`, `backend/src/repositories/knowledge-vector-repository.ts`. The actual repository uses Weaviate `nearVector` search and returns ordered chunk IDs and distances. Its standard embedding service uses an OpenAI API; do not transmit private data. A deterministic local embedding mechanism or synthetic-only hosted embeddings may be used if explicitly selected and recorded, but neither is implemented here.

Failed or missing results must not be treated as empty rankings. Do not assign labels from retrieved results.
4. Convert the reviewed judgments and actual output to Tide Rill v2, using full chunk UUIDs and an explicitly completed judgment set for each query. Preserve all judged positives, including those not returned. Run Tide Rill with `k` fixed in advance and record output and tool version. 5. Review scored results, coverage and errors before considering comparisons, other-tool adapters, or release. Four hand-authored queries are a feasibility check, not a representative benchmark or evidence of state-of-the-art quality.

`tide-rill-input.json` and `tide-rill-report.json` contain the scored run at k=3. Recall@3 was 1.0 for each of the three queries with judged positives; the no-positive query's recall is null. MRR@3 was 1.0 across those three eligible queries because grade 1 counts as relevant. For two queries, the directly answering grade-2 chunk was ranked second behind grade-1 context, so MRR must not be read as direct-answer ranking. This tiny example is not a representative benchmark.
